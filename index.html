Extension to userscript

Pick a Chrome or Firefox extension file and get one .user.js you can paste into Tampermonkey, Violentmonkey or the Userscripts app. Everything happens on your device.

Don't have the file? Get it from a store link

      How to install it on a phone
      
      
        
        
          
      1. Android: in a browser with Tampermonkey or Violentmonkey (Firefox, Edge, Kiwi), open the dashboard, add a new script, delete the template, paste, and save.
        2. 
          
      2. iPhone or iPad: in the Userscripts app for Safari, create a new JS file, paste, and save. Or save the file here and put it in the Userscripts folder, renamed to end in .user.js.
        3. 
          
      3. Open the extension's popup or options from your userscript app's menu, or from the floating button.
        4. 
          
      4. If nothing happens on a strict site, turn off Content Security Policy handling in Tampermonkey's advanced settings.
        5.
